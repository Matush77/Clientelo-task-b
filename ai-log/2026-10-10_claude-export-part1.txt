     Key implementation decisions

     - Cost model (public/js/model.js):
       - fund data comes from the verified facts: TER SPY 0.0945 %, IVV/VOO 0.03
         %, CSPX 0.07 %
       - Fio: USD 7.95 per order, ≈3 % FX, bought quarterly
       - XTB: 0 %, 0.5 % FX
       - ČNB USD rate 21.745 (9. 10. 2026); 7 % p.a. before costs
       - each data point carries its source URL and as-of date
       - the API recomputes all numbers server-side, so client values are never
         trusted
       - tests lock in 3 000 Kč/20 y = CSPX 27 900, IVV/VOO 131 300, SPY 142 100
     - A/B:
       - assignment is ?v=a|b if present, otherwise random 50/50 per page load
       - nothing is stored on the device, so no consent is needed; a reload may
         switch variant, which is documented
       - A = Prague Castle + "Začít investovat"; B = young man + "Spočítat
         poplatky"
     - Funnel events (cookie-free):
       - events: page_view, hero_cta, calc_select, calc_compare, result_view,
         form_open, form_start, help_on, form_submit, lead_ok, lead_error
       - each carries variant, device class and utm_*, linked by an in-memory
         page-load ID
       - server-side, Redis HINCRBY per day, variant and utm_content
       - no IP stored; rate limiting uses a short-TTL hash
     - Cookie consent (showcase): the approved banner is shown on first visit:
       - phone: bottom card
       - tablet: centred card
       - desktop: full-width bar
       - "Přijmout" highlighted; a settings dialog; the footer link "Nastavení
         cookies" reopens it
       - the choice is saved as a strictly necessary setting (localStorage
         veenos_consent, 12 months; after a refusal the banner isn't shown again
         for 6 months)
       - consent-gated loaders for GA4 and Meta Pixel are wired but inactive 
         without IDs (env vars GA4_ID / META_PIXEL_ID empty), so the mechanism
         is demonstrable and nothing third-party loads
       - the README says the banner is part of the showcase
     - Lead flow (api/lead.js):
